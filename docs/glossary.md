# Glossary

- **Branch:** A movable reference to a commit.
- **Clone:** Create a local copy of a remote repository.
- **Commit:** A Git object recording a project snapshot and metadata.
- **Conflict:** A situation where Git cannot automatically reconcile changes.
- **Fetch:** Download remote objects and update remote-tracking references.
- **Fork:** A GitHub-hosted copy of another repository under your account or organization.
- **HEAD:** The current checkout reference, usually pointing to a branch.
- **Index / staging area:** The proposed content for the next commit.
- **Merge:** Combine histories.
- **Pull request:** A GitHub collaboration mechanism to propose and review changes.
- **Rebase:** Replay commits onto a different base.
- **Remote:** A named reference to another repository.
- **Reflog:** Local record of recent reference movements.
- **Tag:** A named reference commonly used to mark releases.
- **Working tree:** The checked-out files in your local directory.
