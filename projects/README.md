# Learning projects

## Project 1 — Personal command journal
Create a repository documenting commands you learn. For each command include purpose, safe example, expected output, and a warning if destructive.

## Project 2 — Team simulation
Use two branches to simulate two developers. Make parallel changes, trigger a conflict, resolve it, and write a short resolution note.

## Project 3 — Pull request practice
Create a small documentation project. Use issues for tasks, a feature branch for each change, and PRs with review checklists.

## Project 4 — Open-source contribution simulation
Fork a repository that welcomes documentation contributions. Read CONTRIBUTING, make a small meaningful improvement, and submit a PR. Follow the maintainer's instructions.

## Project 5 — GitHub Actions learning workflow
Add a workflow that runs a basic validation on pushes and PRs. Experiment with job dependencies and least-privilege permissions.
