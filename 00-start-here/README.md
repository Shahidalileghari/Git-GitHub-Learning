# 00 — Start here

## What is version control?
Version control records changes over time so you can inspect, compare, share, and recover work.

## Git vs GitHub
- **Git** is a distributed version-control system that runs locally and stores project history.
- **GitHub** is a hosted platform built around Git repositories, adding collaboration features such as pull requests, issues, code review, and automation.
- Git works without GitHub. GitHub uses Git, but is not Git itself.

## The basic lifecycle
Working directory → staging area → commit → remote repository.

A commit is a snapshot-like object in a history graph, not simply a saved copy of every file.
