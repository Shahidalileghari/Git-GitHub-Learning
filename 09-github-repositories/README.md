# 09 — GitHub repositories

Learn repository visibility, README files, descriptions, topics, default branches, releases, tags, license selection, and repository settings.

A repository README should explain purpose, setup, usage, examples, contribution expectations, and license. Never publish secrets or private information.

Practice:
1. Create a public learning repository.
2. Add a meaningful description and topics.
3. Add README and MIT license.
4. Clone it locally, make a commit, and push.
