# Exercises — from hello to collaboration

Complete in order. Use a disposable repository for recovery exercises.

1. Configure Git identity and inspect config scopes.
2. Create a repository with three meaningful commits.
3. Stage only selected hunks with `git add -p`.
4. Compare two commits and explain the diff.
5. Create and merge a feature branch.
6. Reproduce and resolve a merge conflict.
7. Compare `restore`, `revert`, and `reset`.
8. Recover a commit using reflog.
9. Push a branch to GitHub and open a PR.
10. Review a PR and submit changes after feedback.
11. Fork an open-source project and configure `upstream`.
12. Create an annotated tag and a GitHub release.
13. Explain why a secret committed by mistake must be rotated.
