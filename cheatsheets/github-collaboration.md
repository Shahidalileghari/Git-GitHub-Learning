# GitHub collaboration cheatsheet

1. Fork the project.
2. Clone your fork.
3. Add original project as `upstream`.
4. Fetch upstream and create a feature branch.
5. Make a focused change and commit.
6. Push the branch to your fork.
7. Open a pull request against the original repository.
8. Respond to review feedback and update the branch.
9. Merge after checks and approval according to project policy.
