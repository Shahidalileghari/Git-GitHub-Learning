# Hello Git practice lab

This folder is a safe starting point for command practice. You can initialize a repository here or copy the files into a temporary folder.

Suggested sequence:
1. `git init`
2. Add a README and commit.
3. Modify a file and inspect `git diff`.
4. Stage and commit.
5. Create a branch and merge it.
6. Create a conflict in a disposable copy.
7. Connect a GitHub remote and push.

Do not run destructive recovery exercises in a repository containing valuable work.
